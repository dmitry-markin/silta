# Contributing

- Open an issue first for anything beyond a one-line fix, so the design is agreed before the code exists. Unannounced PRs may be closed unread.
- Contributions written with AI are welcome when the author understands and has tested every line and says so in the PR. PRs the author can't explain will be closed.
- Submit small PRs, one change each, ideally under 300 lines and never above 1000 lines, with the title written as the changelog line and exactly one of the labels `added`, `changed`, `fixed`, or `removed`. The description should be concise and written in the author's own words.
- Contributions are accepted under the project's `Apache-2.0 OR MIT` licence, as stated in the README.
